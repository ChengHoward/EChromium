# 站点图标：缓存与更新

实现参考本机 Chromium 源码的 `components/favicon/core/favicon_handler.cc` 和 `favicon_backend.cc`：先显示已有图标，再按页面声明的候选地址和缓存有效期决定是否下载；有效期采用源码中的 7 天。

当前是 Electron 外壳中的独立实现，并未接入 Chromium 的 `FaviconService` 数据库，也不等于完整复刻其全部策略。

## 页面与图标的关系

- 以完整页面网址建立映射，保留路径和查询参数，忽略片段；不会把同域所有页面强制显示为同一个图标。
- 多个页面可共享一个图标地址与缩略图；重定向链和同文档导航也会补充页面映射。
- 普通窗口的缓存随 `browser-v1.json` 原子保存。标签恢复、尚未加载的标签、书签栏和书签管理器直接读取缓存，不为展示这些图标额外访问网站。
- 标签总览使用同一组站点图标。网页加载时保留加载指示；没有图标或图像解码失败时显示默认地球图标。
- 对接近纯黑或纯白的图案，在对应低对比的界面模式下加小面积衬底，保持原始站点图案，避免深色模式下黑色图标消失。

## 更新与失效

- 监听 Electron 的 `page-favicon-updated`，使用 Chromium 提供的候选列表。候选地址不变、缓存未过期时直接复用。
- 候选地址变化、超过 7 天或强制刷新页面时重新下载。候选下载失败会尝试下一项，离线时保留上一张有效图标。
- 并发请求按会话和图标地址复用；失败地址在内存中退避 60 秒。单次请求有超时及响应大小上限。
- 页面明确移除所有候选时移除其映射，不影响其它仍使用该图标的页面。
- 导航、关闭、转移、连续变更候选或清除历史后，过期异步回复不得重新写入旧页面映射。
- 清除历史会清理相应页面的图标映射，同时保留书签及其它时间段历史所需的映射。清除网页 HTTP 缓存不会删除已保存的书签图标。

## 隐私与解码

隐私会话使用独立内存缓存，不向普通资料写入；最后一个对应隐私窗口关闭后释放缓存。图标请求使用页面自己的会话，不在浏览器外壳中直接加载远程图片，也不通过第三方图标服务查询。

常见位图直接解码；ICO、SVG 等由独立、无 Node 权限的沙箱网页容器解码，再转换为 32px PNG。解码容器不附着到窗口，内容安全策略仅允许数据图片，禁用外部资源和页面脚本。外壳只接收本地 PNG 数据；缓存加载时重新校验结构与大小。

缓存上限为 256 张图标、约 2 MB 序列化内容，每张最多保留 32 个页面映射；超出后淘汰较旧条目。这是当前预览版的资源边界，未来完整资料管理可迁移到独立数据库。尚未实现 Web Manifest 图标优选、完整多尺寸数据库、导入浏览器图标数据库或跨设备同步。

## 代码与验证

- `src/shared/favicon.ts`：页面规范化、缓存记录、有效期、映射与容量限制。
- `src/main/favicon-service.ts`：会话隔离、请求复用、更新和历史清理。
- `src/main/favicons.ts`：有界下载与沙箱解码。
- `src/renderer/SiteIcon.vue`：统一图标布局与加载失败回退。
- `src/main/smoke-favicons.ts`：真实窗口、PNG／ICO／SVG、缓存复用、更新、重启读取、书签、延迟回复与隐私隔离检查。

运行 `npm test` 与 `npm run smoke`，后者包含真实站点图标检查；所有测试使用本地来源及独立资料。
