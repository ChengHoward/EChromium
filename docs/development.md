# 开发说明

安装和启动步骤见 [README](../README.md#快速开始)。目标平台为 Windows x64，定制发行包固定为 `45.0.0-desktop.3`，来源与摘要记录在 `runtime-lock.json`。

## 运行时与升级

`npm ci` 默认跳过安装脚本。通过 README 中的定制发行地址下载运行时，再执行 `runtime:prepare`。也可指定本机同版本 `electron.exe`：准备脚本复制其所在的完整运行时目录，核对锁定摘要，并只为项目副本设置沙箱读取权限。

升级时可加 `--stage-only` 先写入 `candidate.json`，保留当前启动器。用 `ECHROMIUM_ELECTRON` 指向候选副本，通过集成检查后再不带 `--stage-only` 准备。

普通启动核对运行时清单和实际可执行文件摘要，拒绝旧版本或损坏副本。显式指定 `ECHROMIUM_ELECTRON` 用于临时测试其它构建，会绕过默认运行时选择；运行报告仍记录实际文件摘要。不要只凭 `process.versions.electron` 判断定制发行版本。

## 开发与资料隔离

`npm run dev` 启动界面热更新，开发地址为 `http://127.0.0.1:5188/`。主进程或 preload 修改后须重启开发进程。

开发与普通启动默认使用 `.local/user-data`，不读取旧版用户目录。`ECHROMIUM_USER_DATA` 可指定其它独立资料目录；调试、演示和测试应使用隔离目录，不清空真实用户资料。运行时、缓存、个人数据和测试证据均在忽略规则内。

## 验证范围

```powershell
npm run typecheck
npm test
npm run build
npm run review:ui
npm run smoke
```

`review:ui` 使用隔离资料，生成六主题浅／深色、主题深浅 100、窄窗口和内部页面等 36 张截图，并核对实际可见文本的合成颜色对比。结果位于 `test-results/ui-review`。此入口使用实色截图；系统 Acrylic、真实输入法和辅助技术仍需专项检查。

`smoke` 使用两个本地来源及独立临时资料，检查真实网页隔离、地址栏通信、原生建议、书签层级导入导出、导航、POST 弹窗与拦截、网页对话框、下载记录、主题、标签恢复、批量关闭、网站权限、站点数据清除范围、存储用量与分页、标签压缩与总览、原生查找和中文输入、按时间清除记录、跨窗转移、隐私和关闭确认。

随后连续启动四个独立进程，检查快照写入、多个窗口的重启恢复、最后关闭窗口的完整保留和恢复开关。结果与截图保存在 `test-results/`。

Windows 检查会短暂显示测试窗口，原生点击只向测试进程自有面板发送窗口消息，不移动桌面鼠标；测试外壳保持后台绘制以取得新截图，正式浏览窗口使用正常后台节流。受限环境下执行桌面检查可能需要正常桌面权限，不应通过关闭 Electron 沙箱解决环境访问问题。

## 项目结构

- `src/main/`：窗口、网页容器、导航、下载、存储、权限和材质。
- `src/preload/`：可信界面的受限通信桥。
- `src/renderer/`：Vue 浏览器外壳及内部页面。
- `src/shared/`：协议、地址解析、主题与布局规则。
- `scripts/`、`tests/`：运行、构建与验证。

架构边界、已知问题和进一步开发的约定见 [智能体交接文档](agent-handoff.md)。
