- 标签悬停细节：未激活标签移除默认底色，标签间增加居中的 1px 细分隔线，悬停和激活标签两侧的线条隐藏。悬停与激活共用顶部圆角与底部两侧反向圆角，悬停高亮强度为激活的 45%；总览按钮悬停与打开时使用同一轮廓。分隔线独立于圆角绘制，两侧反向圆角与底色同步淡入／淡出。使用独立临时窗口复核浅／深色的实际悬停样式与截图，构建、格式及类型检查通过。

- 地址栏本地建议：直接搜索／访问、切换当前窗口已打开标签、书签和最近历史，匹配并去重，最多 8 项。定制运行时使用原生 NativePanel 覆盖真实网页，保留地址编辑焦点；支持方向键循环、回车、Esc、输入法组合期间暂停建议。面板行动校验内容版本、标签身份和导航代数。建议专用通信仍校验可信主 frame，输入时不传回整份浏览器状态。

- 下载另存为、进度、暂停、可续传任务的继续、取消、完成后在文件夹中显示；普通下载记录持久化。支持移除单条或清除已结束记录，保留已下载文件；文件不存在时给出明确提示。私密下载记录不落盘。
- 原生独立弹窗保留 Chromium 的 POST、referrer 与 opener 路径。网站权限按来源分别管理摄像头、麦克风、位置与通知，可暂不允许、允许本页、始终允许或始终阻止，并在设置中调整或恢复询问。普通规则持久化，隐私规则只用于关联的临时会话。
- 弹窗防轰炸：同一原始标签和其后代弹窗共享创建额度，关闭弹窗不会刷新短时额度；拒绝后台或关闭中的来源。浏览器栏显示拦截情况，可仅允许本页更多弹窗，并恢复默认限制；重载、跨文档导航或转移窗口后例外失效。允许的窗口仍走 Chromium 原生创建，不将被拦截 POST 改成 GET 重放。拦截状态更新节流，避免高频调用反复广播整个界面。
- Windows 网页 alert／confirm／prompt 使用真实 NativePanel，显示请求 frame 的来源，嵌入页面额外列出顶层来源；来源无法核验时明确标为未知。提示、确认、文字输入、取消、Esc、暂停本页和恢复入口已接通；每页及后代共享对话框额度。离开标签、导航、转移、关闭或源页面销毁时取消旧请求；关闭前确认仍走独立的离开页面流程。
- 旧权限提示在导航、窗口转移、关闭或规则更改后失效；摄像头和麦克风不混为一个授权。未知权限和暂未接入的设备能力默认拒绝。设置页滚动时保留左侧导航。
- 地址栏和主菜单接通 Chromium 原生网站信息面板，连接状态与证书入口由当前已提交页面提供；网站设置事件重新校验当前来源后进入该来源的权限页。来源专页列出四种权限（包括尚未保存的“每次询问”），可切回全部网站。
- 来源设置页增加 Cookie 与网站数据管理：展示适用于此主机的 Cookie 数量、名称、域、路径与属性，不将内容值传入界面；确认后按来源清除 LocalStorage、IndexedDB、CacheStorage、服务工作线程和文件系统存储，并清除同会话中本站已打开顶层页面及弹窗的 sessionStorage。Cookie 单独按主机和父域匹配清除；确认框说明同域、跨端口共享的影响。取消、切走标签或将设置页导航为网页后不执行清除，普通资料和隐私会话独立。
- 清除浏览数据：设置“隐私与数据”、历史页和 Ctrl+Shift+Delete 进入同一检查界面，显示所选记录数量，再由默认取消的原生确认框确认。一小时／一天／七天／全部时间可用于历史和已结束下载记录；保留下载文件、活动任务、书签与权限。Cookie／网站存储及 HTTP 缓存限定全部时间，主进程也拒绝混用限时清除。确认前冻结时间上界，清除期间新增记录保留。普通资料和隐私会话分离，隐私会话不能清除普通历史；共享清除锁避免本站与全局清除同时执行。离开或替换设置页后旧确认失效，操作失败提示可能已部分清除。
- 设置新增网站数据总览：按完整来源展示已知网站的真实配额存储用量、分类用量与主机关联 Cookie 数量，支持搜索、每页 40 项和逐站确认清除。列表结合普通访问记录、当前同会话页面及嵌入 frame、来源权限和 Cookie 域；仅 Cookie 域不虚构 HTTP(S) 来源，只提供 Cookie 清除。清除复用单站数据服务与资料级互斥锁，校验列表版本、当前设置页、页面代数与目标身份，刷新或切走后的旧操作失效。隐私会话不读取普通历史或 Cookie。统计通过同会话临时 about:blank 容器和固定的 Storage.getUsageAndQuota 命令完成，不导航到网站、不接管用户网页的调试连接；统计结束销毁容器，不额外持久化网站索引、Cookie 值或统计快照。
- 单实例唤起、版本化窗口快照与延迟加载；保存普通窗口的正常位置、最大化、标签顺序、选中项、内部页面、固定、静音和缩放，只加载各窗口的活动网页。启动时将位置修正到现有屏幕工作区；关闭最后一个普通窗口前保存完整快照，剩余隐私窗口不将它覆盖为空。兼容旧网址列表；首次网页加载完成后再应用恢复缩放，避免内核导航重置。关闭前确认取消保留活页面，确认离开才销毁。

## 已明确的实现边界

- 只提供默认资料与独立隐私窗口，没有完整多资料管理、标签组、垂直标签或分屏。跨窗口合并支持同一资料，分别新建的隐私会话互不混合。拖动到桌面自动新建窗口、跨窗口整组移动和拖放位置指示仍未实现。
- 启动快照最多保存 10 个普通窗口、每窗最多 100 个标签、合计最多 200 个标签；只处理默认资料，不保存弹出窗口和隐私窗口。网页恢复只重新打开 HTTP(S) 网址，不恢复完整导航历史、POST 请求、表单、滚动位置或网页全屏状态；缩放仍受 Chromium 的同源共享行为影响，不承诺同源标签独立值。没有跨重启的“最近关闭窗口”列表或用户手动挑选崩溃快照的界面。位置修正在启动恢复时执行，实时拔插屏幕和不同 DPI 环境仍需专项验收。旧版网址列表最多恢复 50 个；更新保存时仍保留该兼容字段。
- 重开关闭标签在本次运行期间按资料保留最近 30 个关闭记录，每个记录至多 50 条 URL 导航项，不包含 Chromium pageState。关闭最后一个窗口退出应用后，这个关闭记录栈不会保留。隐私关闭记录与普通窗口隔离，最后一个关联隐私窗口关闭时清除。
- 地址建议只匹配当前窗口标签、至多 2000 个书签与最近 150 个历史网址；没有远程搜索建议、模糊评分、建议内删除历史或跨窗口标签搜索。没有原生面板时，建议列表在浏览器栏内展开，重新安排网页区域，不将普通 HTML 假设为可覆盖原生网页。该回退分支尚未在非 Windows 平台实机验收。
- 书签最多 2000 个、文件夹最多 500 个、层级最多 12 层；导入文件上限 5 MB、一次最多 5000 个书签和文件夹节点。超过容量或深度时整批不写入，拒绝将文件夹移动到自身或后代。暂未提供批量编辑、目录拖放、独立目录排序与同步。只保留最近一次删除的当前管理页撤销记录，撤销恢复到所属目录末尾；目录已不存在时恢复到根位置。书签栏展示前 8 个根文件夹和 15 个根书签，原生菜单每个目录展示前 100 个书签，完整内容可在管理页访问。文件夹与书签分别排列，不保留任意交错顺序；没有导入浏览器专有的图标、时间等附加字段。
- 标签总览当前限于当前窗口，没有跨窗口汇总、总览内拖动重排或分组。截图是最近可获得的网页局部画面，最多取 1600×1000 的可见区域；并非完整网页截图或实时视频。缓存短时间复用，无法复制帧时使用占位，不保证所有后台页面均有图像；不会为了生成预览加载尚未载入的网页。内部页使用名称与图标表示。标签超过最低宽度可容纳的数量后仍会横向滚动。
- 原生查找当前面向支持 NativePanel 的 Windows 平台，最大查询长度 1024。公共行动事件没有键盘修饰符，原生输入框内暂不能可靠区分 Shift+Enter；反向查找使用上一个按钮或 Shift+F3。组合输入状态以运行时诊断读取，该字段尚未包含于分发包的类型声明。完整真实输入法候选窗、读屏与跨屏 DPI 仍需人工验收。
- 按时间清除针对当前每个 URL 的最近一次历史记录，下载记录按任务开始时间筛选；不会从去重历史还原更早访问。定制运行时 clearData／clearStorageData／clearCache 公开接口不提供时间范围，故网站数据与缓存只做全部时间，不宣称按小时清除。全部网站数据清除处理当前资料持久存储和已打开顶层网页的 sessionStorage，嵌入 frame、已关闭标签及特殊分区存储仍需专项验证；不清除 HTTP 认证缓存或最近关闭标签。
- 暂无重启续传。普通下载保存最近至多 500 条元数据，重启前未结束的任务标记为中断，不会误报可继续；当前运行中的可续传状态由真实 DownloadItem 决定。历史界面每个 URL 保留最近一次访问。
- 权限请求只在活动且聚焦的网页中受理，跨来源嵌入请求暂不放行。暂无屏幕共享选择器、设备选择器或完整设备管理；独立弹窗暂不授予这些站点权限。更改权限作用于后续请求，已打开的媒体流需关闭或重载网页停止，系统权限仍可能拒绝访问。
- 来源专页管理单个来源，总览另列已知网站及 Cookie 域。界面最多展示前 200 条 Cookie 元数据；清除会尝试处理全部匹配 Cookie。Cookie 不是按来源隔离的存储，同主机不同端口及共享父域 Cookie 的站点可能同时退出登录；其它主机的 host-only Cookie 保留。sessionStorage 只清除当前运行中匹配来源的顶层页面，不承诺清除跨来源嵌入 frame、已关闭标签的会话或全部分区存储；第三方分区 Cookie 仍需专项验证。网站仍打开时可重新写入数据，失败时提示可能已部分清除。浏览历史、书签、权限规则、全局网络缓存和 HTTP 认证缓存不在这次操作范围内。
- 网站数据总览不是完整的存储来源枚举：内核公开接口缺少全部来源枚举能力，已删除历史、已关闭的第三方嵌入来源及第三方分区数据可能不在列表中。用量仅含 QuotaManager 报告的数据库、离线缓存、服务工作线程和文件系统，不含 Cookie、LocalStorage、sessionStorage 或 HTTP 网络缓存；0 B 不能解释为该网站没有任何数据，读取失败显示“暂无法统计”。Cookie 数量可能跨多个来源共享，不逐行相加。最多列出 4000 项、每页 40 项，统计最多 4 项并发、单次命令约 1.8 秒和整体约 15 秒预算，超时项目保留未统计状态；列表版本仅在内存中保存。逐站清除不等同按 Cookie 域清空全部子域的所有存储。
- 弹出窗口默认每个来源标签最多同时 3 个、10 秒最多创建 3 个，全应用最多同时 8 个；本页例外放宽短时和单页限制，仍受全局 8 个限制。当前公开开窗回调没有可靠的原生临时用户激活字段，尚不能完整区分前台的自动开窗与用户点击；不是完整的 Chromium 弹窗策略，也没有按网站持久例外。用户允许后需在网页中重试，不自动重放被拒绝请求。
- 网页对话框默认每个原始标签及后代在 10 秒内最多显示 3 个，超限暂停本页，用户可恢复；后台、并发请求和失效请求取消。单次等待 2 分钟后取消，特意关闭定制运行时默认 5 秒后自动接受的异步回退。消息最多展示 8000 个字符，输入最多 65536 个字符；对话内容和回复不写入资料快照。未提供 NativePanel 的平台保留原生连续对话框保护，文字输入和跨平台体验尚未验收。无限脚本循环的 CPU 占用仍需后续性能治理。
- 网站信誉服务、打印和 PDF 专项仍需实现或核验。网站信息已经接入真实原生接口，但不同 TLS 状态、证书详情交互、混合内容和跨屏摆放仍需专项验收；界面不把 HTTPS 字符串本身当作连接安全结论。
- 明确要求 popup、尺寸或 new-window 的弹窗是带原生菜单和真实来源标题的独立窗口，没有完整地址工具栏；普通新窗口链接与表单已挂接为浏览器标签。
- 没有密码管理、扩展宿主、PWA 安装、同步、正式安装包、签名和自动更新。当前构建产物是开发运行产物。
- 外壳截图能核对布局与颜色，但不能证明系统实际绘制了 Acrylic。原生窗口截图属于本机单个环境的观察，不代替不同系统偏好与多屏验收。

## Navora 参考与调整

已参考 Host/Page 所有权、标签操作、相邻选择、窗口框架、材质、地址及窗口查找原生面板设计；调色与相邻标签规则按 MIT 许可记录于 THIRD_PARTY_NOTICES.md。聊天会话、Agent 控制、自动对话框决策和关闭后台节流的默认策略没有进入普通浏览模型。测试程序只让独立测试外壳持续绘制，以避免后台旧帧污染页面截图。
